Standalone OBS Studio Browser Source HTML (obs-chat-overlay.html)

Add this exported file as a Local File in an OBS Browser Source (Recommended size: Width 550, Height 800).

1. Streamer.bot WebSocket
In Streamer.bot: Servers/Clients → WebSocket Server → Enable Auto Start (127.0.0.1:8080).
2. Local image.png / sound.mp3
If using image.png border, place image.png in the exact same folder as your exported HTML file.
3. OBS Studio Audio Control
In OBS Browser Source properties, check "Control audio via OBS" if you want to adjust chat volume in OBS.
